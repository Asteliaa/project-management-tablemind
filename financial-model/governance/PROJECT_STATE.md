# Состояние проекта TableMind

Обновлено: 15.11.2026. Здесь хранится изменчивое: версии, коммиты, рабочие деревья, числа, расхождения и решения владельца. Версия без пометки «решение владельца» **не утверждена**.

## 0. Долгосрочная цель

TableMind — долгосрочный проект реального цифрового продукта. Сейчас выполняются курсовая и экономико-финансовая модель (учебный контур). Позже планируется проектирование и разработка приложения (продуктовый контур). Контуры разделены: учебные допущения (условная команда из 7 человек, сроки и бюджет УП, тарифы, «полный старт») не становятся автоматически решениями для реального продукта. Сейчас не создаются код, инфраструктура и окончательная архитектура.
