## Общие свойства шаблонов (по инструкциям и книгам)

- Юрисдикция: Республика Беларусь. Валюта: BYN, денежная единица **тыс. BYN** (500 = 500 000 BYN). Проценты вводятся долями (20 % = 0,20).
- Горизонт в книгах: **01.01.2026–31.12.2030, поквартально, 20 кварталов** (`MODEL.START`, `MODEL.END`, `MODEL.FREQ` в блоке 00). Он не совпадает с горизонтом проекта по ПЗ1 (01.10.2026–30.09.2027). Как их согласовать, должен решить владелец.
- **Внешних ссылок между книгами нет.** Перенос между файлами идёт вручную по техническим кодам. Порядок обновления: 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
- Блок 00 владеет только глобальными параметрами: инфляцией, НДС, начислениями на оплату труда, налогом на прибыль, WACC, Cost of Equity, terminal growth. Тарифы, клиенты, CAC, churn, FTE, зарплаты, CAPEX и долг в 00 не вносятся.
- На входных листах шаблонов **уже стоят примерные числа** (см. таблицу ниже). Это не параметры TableMind.
- Налоговые и правовые параметры инструкции требуют подтверждать на дату модели по НПА. В инструкциях 04–07 упоминается режим ПВТ, а его применимость к TableMind не определена.
