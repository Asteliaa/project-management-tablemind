# Финансовая модель TableMind (бизнес-модель)

Эта папка — **снимок** рабочих материалов экономико-финансовой модели TableMind, чтобы результаты не потерялись. Источник истины — локальный проект владельца (`D:\TableMInd\TableMind_Model\TableMind\`); здесь лежит копия на момент, указанный ниже. Папка не связана с курсовой по управлению проектами (`pz1/`, `pz4/`, `risk-management/`) и не меняет её.

## Статус снимка

| | |
|---|---|
| Снимок сделан (UTC) | см. `SNAPSHOT_TIME.txt` (создан при выгрузке 2026-11-15) |
| Хеши SHA-256 всех файлов | `MANIFEST.sha256` (проверка: `cd financial-model && sha256sum -c MANIFEST.sha256`) |
| Что заполнено | **Только блок 00** (глобальные предпосылки: инфляция, НДС, начисления, налог на прибыль). Остальные книги в этом снимке — рабочие копии шаблонов преподавателя (их хеши совпадают с оригиналами, см. `journals/sha256_исходные_и_рабочие_копии.tsv`); блоки 01+ заполняются другими потоками работы, поэтому новые версии появятся в следующих снимках |
| Что НЕ готово | WACC, CoE, terminal growth в блоке 00 не заполнены; налоговый режим РБ — базовый сценарий, по НПА не подтверждён; тарифы Free/9/19/29 EUR — рабочая ценовая гипотеза, а не подтверждённая рынком цена. Подробности и все открытые вопросы — `governance/PROJECT_STATE.md`, `governance/OPEN_QUESTIONS.md` |
| Пересчёт | Выполнен в LibreOffice (папка `model/_recalc/`), не в Excel. В самой рабочей копии блока 00 нет сохранённых значений (после записи openpyxl) — Excel пересчитает при открытии |

**Числа из книг нельзя считать результатами модели TableMind, пока соответствующий блок не отмечен выполненным в `governance/PROJECT_STATE.md`.** На входных листах шаблонов стоят демонстрационные значения преподавателя.

## Структура

| Путь | Что внутри |
|---|---|
| `model/` | рабочие копии книг 00–07, 01-1, 01-2, 02-1, дашборд и текстовое описание (`*_TableMind.xlsx/.docx`) |
| `model/_recalc/` | результаты пересчёта LibreOffice (для проверки; не заменяют рабочие копии) |
| `journals/` | журнал исправлений шаблонов, реестр предпосылок и источников, хеши «оригинал → рабочая копия» |
| `governance/` | `CLAUDE.md` (правила работы), `PROJECT_MAP.md`, `PROJECT_STATE.md` (состояние, решения владельца, расхождения), `OPEN_QUESTIONS.md`, `TableMind_Model_README.md` (карта книг и потоков) |
| `audit/` | `barrier_index_trace.md` — выписка из раздела 5 PROJECT_STATE: расхождения исследований и трасса индекса барьеров входа (значение → балл → вес → вклад → итог: 3,15 / 3,44 / 2,68, ни одно не утверждено) |
| `scripts/` | расчётные скрипты и скрипт пересчёта, использованные для блока 00 (версии на момент снимка) |
| `sync/` | процедура и скрипт обновления снимка, см. `sync/SYNC.md` |

## Что сюда не входит

Оригиналы преподавателя и архив `Модель (1)`, демонстрационный заполненный пример, папки `_backup`, lock- и tmp-файлы LibreOffice, исследования ЭБ (`TableMind_EB`, отдельный локальный репозиторий) и его рабочие деревья, курсовая презентация. Список — в описании PR.
