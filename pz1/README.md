## 4. Что выполнено

### 1.1 Модель 5W
- **WHAT** — облачный AI-сервис проверки таблиц Excel: веб-аудит финмоделей и надстройка Excel; принцип «LLM предлагает, движок доказывает».
- **WHO** — финансовые аналитики и FP&A, консультанты, бухгалтеры, основатели малого бизнеса; заказчик — основатель стартапа (владелец продукта).
- **WHY** — ошибки есть в 86–94% реальных таблиц; AI-надстройки лидеров рынка сами требуют проверки результата — ниша независимой проверки свободна.
- **WHEN** — старт 01.10.2026, MVP 31.03.2027, публичный релиз — сентябрь 2027, завершение 30.09.2027.
- **WHERE** — браузеры Chrome/Edge/Firefox/Safari, Excel Microsoft 365 (Windows, macOS, веб), хостинг в ЕС.

### 1.2 Бизнес-окружение и «Проблемы → Решения»
Стратегия — ниша самообслуживаемой проверки таблиц, модель freemium SaaS; рынок табличного ПО ≈ 11 млрд $ (+6–8% в год).
Три проблемы и решения: ручная проверка ошибок → автоматический аудит < 60 с; «галлюцинации» AI → детерминированная
верификация каждого изменения; расхождение чисел в тексте и таблице → сверка утверждений с ячейками.

### 1.3 SMART-цель
> До 30.09.2027 командой из 7 человек в рамках бюджета 517 000 BYN разработать и вывести на рынок TableMind — веб-сервис аудита
> Excel-моделей с AI-исправлениями, проверенными детерминированным движком, и надстройку для Excel с проверкой при каждой правке,
> обеспечив precision критичных находок не ниже 90%, аудит файла до 100 тыс. ячеек быстрее 60 секунд и не менее 50 платящих пользователей.

### 1.4 Правила приёмки (5)
precision ≥ 90% и recall ≥ 80% в CI; аудит < 60 с и p95 проверки при правке < 500 мс; 0 «выдуманных» чисел в регрессионном наборе;
сквозной E2E-сценарий во всех браузерах, исправленный xlsx сохраняет формулы и оформление, надстройка в AppSource; нет дефектов blocker/critical, пройден OWASP, файлы удаляются по сроку хранения, опубликованы юридические документы.

### 1.5 Допущения (5)
пилотные пользователи дадут модели для eval-набора; LLM-провайдеры сохранят цены и zero data retention в ЕС; AppSource опубликует
надстройку ≤ 4 недель; лицензия движка пересчёта допускает закрытый SaaS; ключевые участники останутся в команде.
Каждое допущение продублировано риском в реестре рисков.

### 2.1 MoSCoW — Must 8 из 18 (44% < 60%)
| Приоритет | Требования |
|---|---|
| Must (8) | импорт xlsx/csv; аудит правилами и инвариантами; объяснения; исправления через DSL; сверка текста с таблицей; экспорт; регистрация и оплата; надстройка Excel с проверкой при правке |
| Should (3) | ghost-подсказки; палитра Cmd-K; история версий и дифф |
| Could (3) | чистка данных в песочнице; вопросы по данным (SQL); пользовательские инварианты |
| Won’t (4) | собственный редактор; enterprise (SSO, SOC 2); коннекторы к БД и Google Sheets; исполнение VBA |

### 2.2 Исключения (5)
исполнение макросов VBA; замена Excel; ручная экспертная проверка моделей; мобильное приложение и корпоративные коннекторы;
обучение собственной модели и сертификация SOC 2 / ISO 27001.

### 3. Ограничения (6 категорий)
- **Технические:** Python 3.12 + FastAPI, PostgreSQL, Redis, DuckDB, Next.js, Office.js; xlsx/csv до 1 млн ячеек; нужен интернет.
- **Правовые:** GDPR, Закон РБ № 99-З «О защите персональных данных», 152-ФЗ — только при пользователях из РФ; PCI DSS через Stripe; лицензии open-source; правила AppSource.
- **Организационные:** 7 человек, 57 чел.-мес.; спринты по 2 недели; ворота Gate 1–4.
- **Временные:** ТЗ 31.10.2026, MVP 31.03.2027, бета v1 — июль 2027, завершение 30.09.2027.
- **Бюджетные:** 517 000 BYN = база 470 000 + резерв 47 000 (10% от базы); оплата труда 427 500 BYN (57 чел.-мес. × 7 500 BYN с учётом 34% ФСЗН).
- **Пользовательские:** базовое владение Excel, обучение не требуется.
