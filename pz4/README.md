## 1. Цель работы

Освоить календарно-сетевое планирование: построить иерархическую структуру работ (WBS), оценить длительности, установить
взаимосвязи, рассчитать ранние/поздние сроки и критический путь, построить диаграмму Ганта.

## 2. Задачи (по заданию, слайд «задание»)

1. **WBS** — 12–15 укрупнённых работ с кодами 1.0, 2.0 …; верхний уровень — название проекта, второй — этапы работ.
2. **Длительности** — в месяцах, экспертно или по PERT: (O + 4M + P) / 6.
3. **Взаимосвязи** — таблица «Код работы / Название работы / Непосредственные предшественники».
4. **Диаграмма Ганта** — работы по вертикали, месяцы по горизонтали, полосы длительностей, последовательность и связи, критический путь цветом.

Дополнительно по теории занятия: прямой и обратный проход (ES, EF, LS, LF, TS) и сетевой график методом предшествования (PDM).

### 3.4 Заполненный «Планировщик проекта»
- Лист **«ТАБЛИЦА ДАННЫХ»**: 15 работ вместо демо «раб1…раб7»; D и E — номера предшествующих/последующих работ (№ = код WBS: 1 → 1.0);
  **F (ранний старт)** = `MAX(H предшественников)`, **H** = F + G, **J (поздний финиш)** = `MIN(I последователей)`, **I** = J − G,
  **K (резерв)** = I − F, **L** = `ЕСЛИ(K=0;"ДА";"НЕТ")`. Периоды считаются от 1 (период 1 = октябрь 2026), поэтому EF/LF — номер месяца, следующего за окончанием.
- Лист **«Планировщик проекта»** берёт данные формулами и строит диаграмму условным форматированием: критические работы — оранжевые,
  остальные — фиолетовые. Ячейка **J2 «Рассматриваемый период» = 6** подсвечивает март 2027 (релиз MVP).
- Листы «Пример 1» и «Пример 2» — примеры преподавателя, оставлены без изменений.

## 4. Как открыть и работать с файлами

**Отчёт (.docx):** откройте в Word; титульный лист заполнен (Земляник Р.В., гр. 60121).

**Планировщик (.xlsx)** — открывать в **Microsoft Excel 2016+ / Microsoft 365** (в LibreOffice формулы тоже считаются):
1. Откройте файл → при предупреждении нажмите **«Разрешить редактирование»**. Формулы пересчитываются автоматически при открытии.
2. Перейдите на лист **«Планировщик проекта»** — это диаграмма Ганта.
3. Чтобы подсветить другой месяц, введите номер периода (1–12) в ячейку **J2**.
4. Чтобы проверить сценарий «что если», на листе **«ТАБЛИЦА ДАННЫХ»** измените длительность в столбце **G** (например, 12.0 «Надстройка Excel» с 3 на 4):
   пересчитаются ранние/поздние сроки, резервы, критический путь и полосы на диаграмме.
5. Столбцы F, H–L содержат формулы — не вводите туда значения вручную.

**Приложение с формулами PERT/CPM:** [`appendix/`](../appendix/README.md) — там можно менять оценки O, M, P.

**Автоматическая проверка требований:**
```bash
# из корня репозитория; нужен Python 3.9+
pip install python-docx openpyxl
python tools/verify_works.py pz4 .
```
Скрипт печатает таблицу «требование — статус» и завершается с кодом 0, если все обязательные требования выполнены
