# Управление проектами — практические работы по проекту TableMind

Практические занятия по дисциплине «Управление проектами» (БГУИР, группа 60121, слушатель Земляник Р.В.), выполненные на примере проекта **TableMind** —
AI-сервиса проверки Excel-моделей (веб-аудит + надстройка для Excel, принцип «LLM предлагает, движок доказывает»).

## Ключевые параметры проекта (едины во всех работах)

- Срок: 01.10.2026 – 30.09.2027 (12 месяцев); ТЗ — 31.10.2026, MVP — 31.03.2027, открытая бета с оплатой — 01.06.2027, бета v1 — июль 2027, релиз — сентябрь 2027.
- Критический путь: 1.0 → 3.0 → 6.0 → 9.0 → 12.0 → 13.0 → 14.0 → 15.0.
- Условная команда из 7 человек (57 чел.-мес.), бюджет 517 000 BYN, резерв 47 000 BYN (10% от базовой стоимости).
- MoSCoW: Must 8 из 18 (44%).
- Риски: 19 (4 высоких, 13 средних, 2 низких) по порогам шаблона 0,505 / 0,14.

## Как пользоваться

1. Скачайте репозиторий: **Code → Download ZIP** (или `git clone https://github.com/Asteliaa/project-management-tablemind.git`).
2. Отчёты `.docx` открывайте в Microsoft Word; таблицы `.xlsx` — в Microsoft Excel 2016+ / Microsoft 365
   (подписи точек на карте рисков видны только в Excel).
3. Титульные листы заполнены: слушатель гр. 60121 Земляник Р.В., руководитель И.В. Кашникова.

## Автоматическая проверка требований

`tools/verify_works.py` проверяет каждую работу по условиям занятия (разделы шаблона, количество элементов, формулы, пороги, критический путь и т. д.).

```bash
pip install python-docx openpyxl
python tools/verify_works.py pz1 .
python tools/verify_works.py pz4 .
python tools/verify_works.py risk .
python tools/verify_works.py appendix .
python tools/verify_works.py cross .   # согласованность работ между собой
```

Результаты проверки при добавлении работ — в [CHECKLIST.md](CHECKLIST.md).
