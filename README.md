# Управление проектами — практические работы по проекту TableMind

Практические занятия по дисциплине «Управление проектами» (группа 60121), выполненные на примере проекта **TableMind** — AI-сервиса проверки Excel-моделей (веб-аудит + надстройка для Excel, принцип «LLM предлагает, движок доказывает»).

## Состав

| Папка | Работа | Файлы |
|---|---|---|
| `pz1/` | ПЗ1 «Разработка концепции проекта» | отчёт по шаблону преподавателя: 5W, бизнес-окружение, SMART, правила приёмки, допущения, MoSCoW, исключения, ограничения, декомпозиция, стейкхолдеры, выводы |
| `pz4/` | ПЗ4 «Календарно-сетевое планирование» | отчёт (WBS, PERT, связи, CPM, сетевой график PDM, диаграмма Ганта) и заполненный шаблон «Планировщик проекта» |
| `risk-management/` | Управление рисками | заполненный шаблон «Карта рисков в Excel»: 18 рисков, пороги шаблона 0,505 / 0,14, подписи точек из ячеек |
| `appendix/` | Приложения | книга с расчётами PERT/CPM, расширенный реестр рисков (методы, ответственные, остаточный риск), рисунки |

## Ключевые параметры проекта

- Срок: 01.10.2026 – 30.09.2027 (12 месяцев), MVP — 31.03.2027.
- Критический путь: 1.0 → 3.0 → 6.0 → 9.0 → 12.0 → 13.0 → 14.0 → 15.0.
- Условная команда из 7 человек (57 чел.-мес.), бюджет 517 000 BYN с резервом 10% от базовой стоимости.
- Риски: 4 высоких, 12 средних, 2 низких.

## Перед сдачей

- Вписать ФИО на титульных листах `pz1` и `pz4`.
- Открывать xlsx в Microsoft Excel: подписи точек на карте рисков берутся из ячеек и не отображаются в LibreOffice и предпросмотрах.
